第1頁｜理解通分｜Equivalent fractions

教材用途
P5分數加減法示範教材（工作坊原創）。教師應按本校教學進度調整。

學習目標
理解通分的意義；計算異分母真分數加減；以最簡分數表達答案。

已有知識
分子、分母、等值分數、倍數及約分。此次不涉及帶分數或負數。

概念一：份量單位要相同
分母表示把同一個整體平均分成多少份。加減前，先把分數改寫成相同分母。

概念二：等值分數
分子和分母同乘同一個非零整數，分數值不變。例如：1/2 = 2/4 = 3/6。

示例：1/2 + 1/3
2和3的最小公倍數是6。1/2 = 3/6；1/3 = 2/6。
因此 1/2 + 1/3 = 3/6 + 2/6 = 5/6。

想一想
為甚麼1/2 + 1/3不是2/5？請用「每份大小」解釋。

術語對照
numerator：分子；denominator：分母；equivalent fractions：等值分數。

第2頁｜計算與解釋｜Calculate and explain

示例一：1/4 + 1/6
最小公分母是12。1/4 = 3/12；1/6 = 2/12。
答案：3/12 + 2/12 = 5/12。

示例二：3/4 - 1/6
3/4 = 9/12；1/6 = 2/12。
答案：9/12 - 2/12 = 7/12。

示例三：5/6 - 1/3
1/3 = 2/6，所以5/6 - 2/6 = 3/6 = 1/2。
完成計算後，要檢查答案能否約分。

解題程序
找公分母 → 分子分母同步擴分 → 分子相加或相減 → 分母不變 → 約分及檢查。

可能錯誤一
把分母也相加。提醒：相同大小的份數相加，每份大小不變。

可能錯誤二
擴分只改分母、不改分子。提醒：必須保持分數值相等。

可能錯誤三
計算後忘記約分。提醒：檢查分子與分母是否仍有大於1的公因數。

教師備註
以上是設計練習時可考慮的錯誤，並非對本班學生的實際診斷。

第3頁｜練習與應用｜Practice and apply

課堂練習
1. 1/2 + 1/4     2. 2/3 - 1/6
3. 1/3 + 1/4     4. 5/6 - 1/4

錯誤分析
一名虛擬學生說：「1/2 + 1/3 = 2/5，因為分子分母都相加。」
請指出錯誤，寫出正確計算，並解釋通分的作用。

生活應用
一條彩帶長3/4米，剪去1/6米。還剩多少米？請列式並寫上單位。

練習答案（教材用）
1. 3/4；2. 1/2；3. 7/12；4. 7/12。
錯誤分析：3/6 + 2/6 = 5/6；生活應用：3/4 - 1/6 = 7/12米。

檢查答案的方法
重新代入原題計算；加法答案應大於每個正加數；本教材減法答案應非負。
