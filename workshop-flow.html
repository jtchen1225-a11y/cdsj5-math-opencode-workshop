⏱️ 120 分鐘逐分鐘實操流程

嚴格對齊 SKILL.md 之固定 120 分鐘教學動線（10+10+10+12+8+10+15+20+15+7+3 = 120 min）。
前半場（0–60分）直達首份備課成果；後半場（60–120分）深耕分層、同步修訂、重用與課堂難題沉澱。

🔍 放大黑板 00–10 min（10分鐘）

一、看見終點：展示 4 大成果與專案地圖

👨‍🏫 講師行動與投影

• 0:00 投影 output/ 最終 4 個資料夾與檔名成果。
• 0:01 明確宣告：今天不是學無目的的聊天，而是讓 Agent 在專案中真實完成工作。
• 0:03 重申紅線：使用示範教材、不輸入學生真實個資、不共用 API Key。
• 0:06 說明完整學習迴圈：教材 → 規則 → 需求確認 → 備課 → 分層 → 修訂 → 重用。

👩‍🏫 學員行動

• 只看投影、不急於操作。
• 確認自己在會場中的 A / B / C / D 組別。
• 在心中預想一項自己平時最耗時的數學備課環節。

🎯 階段目標：全員看見終點，不陷入安裝枝節與術語焦慮。A/B/C/D 不發請求。
🔍 放大黑板 10–20 min（10分鐘）

二、啟動專案：確認 OpenCode 與教材環境

👨‍🏫 講師行動與投影

• 演示雙擊 01_啟動OpenCode培訓.bat。
• 投影展示專案目錄結構：AGENTS.md、materials/、requirements/、output/。
• 強調 Agent 必須在專案根目錄執行，而不是在外部隨機視窗中發散對話。

👩‍🏫 學員行動

• 雙擊 01_啟動OpenCode培訓.bat 啟動 OpenCode。
• 檢查終端機視窗，確認能看到 materials/ 內的示範教材 PDF。
• 保持待命，不要自行提前輸入其他指令。

🎯 階段指標：≥90% 老師順利進入正確 Workshop 工作區；有阻礙者即時交技術助手處理。
🔍 放大黑板 20–30 min（10分鐘）

三、讀懂 AGENTS.md：建立專案持續規則

👨‍🏫 講師行動與投影

• 20:00 提問：「為什麼 Agent 知道不能覆蓋原教材、只能寫入 output/？」
• 22:00 開啟 AGENTS.md。解說：澳門繁中、術語一致、Input 只讀、Output 才寫、嚴禁學生個資。
• 26:00 核心定義：Prompt 是這次做甚麼；AGENTS.md 是每次都必須遵守的憲法。

👩‍🏫 學員行動

• 複製發送 Prompt 1，讓 Agent 摘要專案規則與目錄地圖。
• A/B/C/D 錯峰送出：
  15:00 A組 ｜ 15:20 B組 ｜ 15:40 C組 ｜ 16:00 D組。
• 對照 Agent 回答，確認規則被忠實理解，暫不改任何檔案。

📋 前往 Prompt 1：認識工作區與規則
🎯 階段指標：老師能用自己的話說出 Prompt 與 AGENTS.md 的差別。
🔍 放大黑板 30–42 min（12分鐘）

四、讀取真實教材：專業分析先於題目生成

👨‍🏫 講師行動與投影

• 示範調用 textbook-analysis skill 讀取 materials/ 內的 PDF 教材。
• 說明優秀的教學設計必須先萃取：核心概念、先備知識、表徵語言、常見迷思。
• 巡視現場確認沒有人跳過分析直接產出整份考卷。

👩‍🏫 學員行動

• 發送 Prompt 2，指示 Agent 閱讀教材並在對話畫面中輸出結構化分析表。
• A/B/C/D 錯峰送出：
  35:00 A組 ｜ 35:20 B組 ｜ 35:40 C組 ｜ 36:00 D組。
• 快速核對教材分析內容，確認符合小學數學專業算理。

📋 前往 Prompt 2：讀取並分析教材
🎯 階段指標：Agent 輸出核心概念與迷思；未建立任何檔案；PDF 讀取失敗時能按規則主動停止報告。
🔍 放大黑板 42–50 min（8分鐘）

五、教師確認需求：形成 task-spec.md 規格書

👨‍🏫 講師行動與投影

• 演示「需求訪談」機制：Agent 不應隨意腦補年級、課時、題數。
• 限制 Agent 一次只問最重要的 6 個問題，並將確認結果寫入 requirements/task-spec.md。
• 宣導原則：規格由教師確認，確定前不得盲目動工。

👩‍🏫 學員行動

• 發送 Prompt 3，要求 Agent 提出不超過 6 個關鍵確認問題。
• 教師簡要回答：年級（P5）、課堂階段（鞏固練習）、題數（8-10題）、分層要求、附答案。
• 檢查 Agent 建立的 requirements/task-spec.md 狀態是否改為 confirmed。

📋 前往 Prompt 3：需求確認訪談
🎯 階段指標：requirements/task-spec.md 建立完成，狀態為 confirmed。
🔍 放大黑板 50–60 min（10分鐘）★ 關鍵半程里程碑

六、完成第一次備課成果：生成第一版課堂材料

👨‍🏫 講師行動與投影

• 投影展示 output/01-first-version/ 目錄。
• 解說規範：緊扣教材、題目層次遞進、保留教師修改標籤、學生版與答案版分離存檔。
• 宣布「第 60 分鐘成果檢查點」，確保全體教師皆拿到第一份產出。

👩‍🏫 學員行動

• 確認 task-spec.md 後，發送 Prompt 4 生成第一版教材。
• A/B/C/D 錯峰送出：
  50:00 A組 ｜ 50:20 B組 ｜ 50:40 C組 ｜ 51:00 D組。
• 在專案中打開 output/01-first-version/ 檢視生成檔案。

📋 前往 Prompt 4：第一次備課生成
★ 第60分鐘通過標準：≥90% 老師成功在 output/01-first-version/ 產出第一版可用教材與教師版解答。
60–65 min（5分鐘）

☕ 微休息與技術追趕（Buffer）

現場暫停發送新請求。講師投影回顧：Prompt → 規則 (AGENTS.md) → 專業技能 (Skill) → 規格 (task-spec.md) → 第一版成果。
技術助手協助少數進度落後者補上第 60 分鐘成果。

🔍 放大黑板 65–75 min（10分鐘，累計至75分）

七、做一次分層：A支援 / B基準 / C挑戰

👨‍🏫 講師行動與投影

• 投影對比兩種「假分層」與「真分層」：單純改數字不是分層，改變認知支架與思維層次才是分層。
• 解說三層定位：A 支援（增加表徵支架）、B 基準（常規要求）、C 挑戰（推理、比較、辨析）。
• 強調：不從零重來，直接基於 output/01-first-version/ 進行分層。

👩‍🏫 學員行動

• 發送 Prompt 5 生成分層版本。
• A/B/C/D 錯峰送出：
  66:00 A組 ｜ 66:20 B組 ｜ 66:40 C組 ｜ 67:00 D組。
• 檢查 output/02-differentiated/ 內的檔案與差異對照表。

📋 前往 Prompt 5：分層學習材料設計
🎯 階段指標：三份版本皆有實質教學支架差異，核心概念不變，數學正確性完整保留。
🔍 放大黑板 75–95 min（20分鐘）

八、做一次同步修訂：模擬真實條件變更與聯動更新

👨‍🏫 講師行動與投影

• 引入突發教學情境：「學校活動調整，本節課只剩 30 分鐘，且剛才課堂發現學生容易直接把分母相加，必須加入一個典型錯因辨析題。」
• 示範 Agent 先分析受影響檔案（學生版、教師答案、時間標籤），再同步連鎖修訂。
• 重點：AI Agent 的價值在於在專案脈絡中「管理修改」，而非盲目重新生成覆蓋原檔。

👩‍🏫 學員行動

• 發送 Prompt 6，輸入指定修訂要求。
• 先聽取 Agent 回報將影響哪些檔案，確認後才執行。
• 檢視 output/03-revised/ 與自動產出的 change-summary.md，確認歷史版本完整無缺。

📋 前往 Prompt 6：專案同步修訂
🎯 階段指標：output/03-revised/ 生成且關聯檔案同步更新，附 change-summary.md。
🔍 放大黑板 95–110 min（15分鐘）

九、再次重用：保留專案長期規則，換入新課題

👨‍🏫 講師行動與投影

• 現場提問：「如果下週要備下一個單元，我們需要重新設定一次 OpenCode 嗎？」
• 證明重用價值：AGENTS.md 依然生效，工作模式依然生效，直接換入新單元需求。
• 示範將新成果存入 output/04-reused/。

👩‍🏫 學員行動

• 發送 Prompt 7，輸入另一個數學單元（如「分數與小數互化」或「帶分數加減」）。
• 觀察 Agent 複用既有規則，僅重新確認新任務規格，並將成果輸出至 output/04-reused/。
• 體會專案資產的持久累積效應。

📋 前往 Prompt 7：新任務專案重用
🎯 階段指標：老師未重新配置專案即可在 output/04-reused/ 產出全新課題教材。
🔍 放大黑板 110–117 min（7分鐘）

十、教師親自驗收：AI 產出 ≠ 完成，驗收才是完成

🔍 9 大驗收清單（Teacher Checklist）

✓ 數學算理正確性：逐題重算，通分、約分、算式與教師答案完全正確無誤。
✓ 學習目標對齊：題目完全扣合小學五年級/四年級課程，無偏題或未學超綱概念。
✓ 學生語言可讀性：文字題敘述符合澳門小學生生活經驗與閱讀水平，無生澀機器翻譯腔。
✓ 難度坡度合理性：基礎題與挑戰題有清晰的台階，不是純粹數字變大。
✓ 分層具實質差異：A 支援版有直觀圖形/表格支架，C 挑戰版有逆向思考或多步推理。
✓ 修訂一致性傳導：教學時間與題數調整後，教師版與學生版同步更新。
✓ 原始教材保護：materials/ 內的 PDF 完好無缺，沒有被意外改動。
✓ 新課題重用成功：output/04-reused/ 成功生成且結構清晰。
✓ 列印與排版空間：若輸出 HTML 或學習紙，預留了足夠的學生算式作答空間。
🔍 放大黑板 117–120 min（3分鐘）★ 培訓閉環

十一、帶一個真實課堂難題離場：下一場培訓入口

👨‍🏫 講師行動與結語

• 總結 3 個核心詞：Prompt＝這次做甚麼；AGENTS.md＝每次都守甚麼；Skill＝專業流程。
• 結尾金句：「AI 時代守本心：把時間還給教學判斷與學生。」
• 指示每位老師在專案中建立 notes/next-workshop-problem.md。

👩‍🏫 學員行動

• 發送 Prompt 8 建立範本。
• 親筆填入一項自己下週即將面對的真實教學難題（課題、學生易錯點、期望 Agent 協助項目）。
• 存檔專案，安心下課！

📋 前往 Prompt 8：記錄課堂問題離場
🎯 階段指標：notes/next-workshop-problem.md 存入每位老師專案中，成為下一期培訓入場券。
