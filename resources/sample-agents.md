# 小學數學教材專案規則 AGENTS.md

> 存放路徑：專案根目錄 `AGENTS.md`  
> 適用對象：聖若瑟教區中學第五校小學中英文部數學教師

## 1. 對象與語言規範
- 本專案供聖若瑟教區中學第五校小學中英文部數學教師使用。
- 每次備課開始時，先確認年級、部別、單元、學生程度、使用時間及輸出形式。
- 中文部使用澳門常用繁體中文；英文部使用適合該年級的清晰英語。
- 雙語教材使用一致的數學術語（例如：Numerator 分子、Denominator 分母、Common Denominator 公分母、Simplest Form 最簡分數）。
- 教材示例的 P5/P4 標籤不代表已自動核對本校教學進度，需由教師最後把關。

## 2. 工作流程與邊界
1. **先讀取指定教材**：明確交代實際讀取的文件、頁面和不確定之處；不得憑空捏造未提供的知識點。
2. **區分教材事實與教學推測**：分清教材原有內容與推測的常見錯誤；不要把推測當成學生客觀診斷。
3. **需求確認**：只追問尚未確定的重要要求，每次最多六題，一次性列出。
4. **規格先於產出**：將需求寫入 `requirements/task-spec.md`，初始狀態為 `draft`。
5. **教師確認才開工**：教師明確確認後，將狀態改為 `confirmed`，方可製作最終教材。
6. **分離存放**：最終成果放入 `output/`；學生版和教師答案必須分開存檔。
7. **嚴格驗收檢查**：逐題重新計算，檢查題意、難度梯度、語言規範、作答空間與列印格式。
8. **客觀陳述**：如未實際開啟瀏覽器或檢查列印預覽，必須說明尚未驗證，不能宣稱已通過。

## 3. 檔案與工具安全守則
- **來源保護**：不得修改或刪除 `materials/` 和 `backup/` 的原始內容。
- **權限控制**：只處理本專案所需文件。缺少解析工具時，先說明，不自行安裝或更改系統設定。
- **讀取備援**：PDF 讀取失敗時，可在教師同意後改用備用文字檔，並清楚標明來源。
- **自包含格式**：生成之 HTML 應內含 CSS，不依賴外部字型、圖片、程式庫或網絡；支援標準 A4 列印。
- **拒絕偽裝**：不要把 HTML 副檔名改成 docx 或 pdf 來冒充格式轉換。

## 4. 教學倫理與個資隱私
- **不虛構內容**：不虛構教材內容或課程要求，不超出已確認的知識範圍。
- **去識別化**：如教材含真實學生姓名、成績、照片或聯絡資料，立即停止讀取並要求提供去識別化副本。
- **座號識別性**：座號仍可能識別學生個資，不視為完全匿名。練習紙只保留空白填寫欄。
- **安全防護**：絕不在專案中記錄 API Key 或帳戶密碼。
- **教師核心地位**：教師負責最終教學判斷；遇到不確定性應直接說明，共同維護課堂專業。
