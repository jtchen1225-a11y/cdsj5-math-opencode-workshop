# 分層工作紙 Skill

1. 只根據已可靠讀取的教材概念設計題目。
2. 預設三層：A 基礎理解、B 應用、C 推理/解釋。
3. 每題標註主要目標：Knowing / Applying / Reasoning（若適用）。
4. 避免只改數字的重複題；加入圖像/語言/情境等多元表徵描述。
5. 提供完整答案；開放題提供可接受答案要點。
6. 如教師指定年級、題數、課時或難度，以教師要求優先。
7. 所有檔案產出只寫到 `02_Output/`。
