# OpenCode 40 人培訓 Starter Pack V2

**版本：2026-09-16**

## 教師課前只做 4 件事
1. 閱讀 `00_Node.js與OpenCode自助安裝指南.docx`。
2. 自行安裝 Node.js LTS。
3. 在 cmd 執行 `npm install -g opencode-ai`。
4. 完成 Workspace/API Key 連接，雙擊 `00_一鍵檢查環境.bat`。

## 正式培訓
雙擊 `01_啟動OpenCode培訓.bat`，按講師指示依序做 `04_OpenCode-Math-Workshop/03_Prompts/` 的任務。

## V2 與 V1 的主要差異
- 把 Node.js 自助安裝納入正式流程。
- 修正 OpenCode npm 安裝指令為 `npm install -g opencode-ai`。
- 免費模型改為「上課前動態確認」，不再假設 DeepSeek V4 Flash 免費。
- 新增 `AGENTS.md`。
- 新增 3 個 `.opencode/skills/`：教材分析、工作紙生成、課堂設計。
- 新增 `opencode.json` 基礎安全權限。
- 新增一鍵環境檢查與一鍵啟動 BAT。

## 不在第一堂安裝
GitHub、Obsidian、NotebookLM MCP、Firebase、Supabase、Ollama、Gemini API、GPT Image。
