📋 實操提示詞庫（Prompt Playbook）

提供 8 大核心教學階段的精準 Prompt。嚴格限定 Agent 邊界，給初學者教師一條最可靠、最清晰的路徑。
點擊右上方「一鍵複製」即可將指令貼入 OpenCode。現場請依照 A/B/C/D 錯峰節奏送出。

快速跳轉： P1 讀取規則 P2 教材分析 P3 需求訪談 P4 第一次備課 P5 分層設計 P6 同步修訂 P7 再次重用 P8 離場問題 ★ V2 整合任務
Prompt 1 第 20–30 分鐘｜讀懂規則

認識工作區與 AGENTS.md 邊界（不改動任何檔案）

✔ Agent 應該做
條列回答專案用途、規則限制、產出目錄，以及需要向老師確認的項目。
✘ Agent 不應該做
不得建立或修改任何檔案，不得擅自開始生成教材。
📁 預期檔案產出
僅在畫面條列文字回答，無檔案寫入。
Prompt 1｜點擊右側按鈕複製 
請先閱讀本專案的 AGENTS.md。

不要開始產出教材。

請先用簡短條列告訴我：
1. 你理解這個專案的用途是甚麼；
2. 你必須遵守哪些規則；
3. 你之後產出的檔案應該放在哪裡；
4. 有哪些地方需要先向老師確認。
Prompt 2 第 30–42 分鐘｜教材分析

讀取真實示範教材並進行學科分析（分析先於生成）

✔ Agent 應該做
可靠讀取 materials/ 內的示範 PDF，分析核心概念、先備知識、常見迷思與重要表徵。
✘ Agent 不應該做
不得直接生成考卷；若 PDF 無法解析，應立即報告，絕不可自行編造教材內容。
📁 預期檔案產出
在 OpenCode 畫面中以結構化表格或條列呈現，無檔案寫入。
Prompt 2｜點擊右側按鈕複製 
請閱讀 materials/ 內的示範教材。

目前只做教材分析，不要直接生成學習單。

請整理：
1. 本課核心數學概念；
2. 學生需要具備的前置知識；
3. 可能出現的常見錯誤或迷思；
4. 教材中值得保留的題型或表徵；
5. 如果要設計一份課堂學習單，你還需要向我確認甚麼。
Prompt 3 第 42–50 分鐘｜教師確認需求

需求規格訪談與寫入 task-spec.md

✔ Agent 應該做
向老師提出不超過 6 個最關鍵問題（年級、階段、題數等），回答後寫入規格書。
✘ Agent 不應該做
不要問能直接從教材知道的事情；寫完規格書後必須停下來等待確認，不可立即動工。
📁 預期檔案產出
requirements/task-spec.md（初始為 draft，教師確認後改 confirmed）。
Prompt 3｜點擊右側按鈕複製 
根據你剛才讀到的教材，請用不超過 6 個問題向我確認這次學習單的必要規格。

一次只問最重要的問題，不要問可以從教材直接得到答案的事情。

我回答後，請把最後確認的規格寫入：
requirements/task-spec.md

寫完後先停下來讓我確認，不要立即生成成品。
Prompt 4 第 50–60 分鐘｜成果 1 里程碑

生成第一次備課成果（緊扣規格、雙版本存檔）

✔ Agent 應該做
依照 AGENTS.md、教材與 task-spec.md 生成第一版學習單與教師解答，提供人工核對重點。
✘ Agent 不應該做
不加入教材無依據的超綱算理；不把答案和題目混在同一份學生紙中。
📁 預期檔案產出
output/01-first-version/ 目錄下的學生版與教師答案版。
Prompt 4｜點擊右側按鈕複製 
我已確認 requirements/task-spec.md。

現在請依照：
- AGENTS.md
- materials/ 內的教材
- requirements/task-spec.md

完成第一版可直接使用的課堂學習材料。

要求：
1. 不要加入教材沒有依據的知識點；
2. 題目次序要有學習坡度；
3. 保留教師可再修改的空間；
4. 如需要答案，另外整理教師版；
5. 所有檔案寫入 output/01-first-version/。

完成後請列出：
- 你建立了哪些檔案；
- 每個檔案的用途；
- 哪三個地方最值得老師人工檢查。
Prompt 5 第 65–75 分鐘｜成果 2 分層設計

分層學習材料設計（A支援 / B基準 / C挑戰）

✔ Agent 應該做
基於第 1 版成果進行真正教學支架分層，產出對照表格說明具體差異。
✘ Agent 不應該做
不得從零重新設計一份互不相干的材料；不得只改數字或僅改標題。
📁 預期檔案產出
output/02-differentiated/（包含支援、基準、挑戰 3 個版本與比較表）。
Prompt 5｜點擊右側按鈕複製 
不要重新設計一份完全不同的學習單。

請以 output/01-first-version/ 的版本為基礎，做一次真正的分層。

共同要求：
- 核心學習目標相同；
- 核心概念相同；
- 不因分層而降低數學的正確性。

請建立：
A. 支援版：增加提示、步驟、表徵或例題支架；
B. 基準版：保留目前主要難度；
C. 挑戰版：增加需要解釋、比較、推理或遷移的任務。

把分層版本寫入：
output/02-differentiated/

完成後請用一個表格說明三個版本到底「改了甚麼」，不要只說難度不同。
Prompt 6 第 75–95 分鐘｜成果 3 同步修訂

同步修訂：條件變更時的跨檔案一致性維護

✔ Agent 應該做
先說明受影響的關聯檔案，經確認後同步更新相關檔案，並產出差異對照清單。
✘ Agent 不應該做
嚴禁覆蓋既有的 01 與 02 目錄；不得只改學生版卻漏掉答案版。
📁 預期檔案產出
output/03-revised/ 與 change-summary.md。
Prompt 6｜點擊右側按鈕複製 
現在模擬真實備課中的臨時修改。

新的要求是：
課堂時間由 40 分鐘縮短為 25 分鐘，請將題目精簡為 5 題；但必須加入 1 題針對「分母直接相加」常見迷思的錯誤辨析題，且教師答案版必須同步更新評分要點。

請先告訴我：
1. 這個改動會影響哪些既有檔案；
2. 每個檔案需要改甚麼；
3. 哪些內容不應被改動。

等我確認後，再同步更新相關內容。

更新後：
- 新版本放入 output/03-revised/；
- 不要覆蓋 output/01-first-version/ 或 output/02-differentiated/；
- 最後提供一份 change-summary.md，列出改動前後差異。
Prompt 7 第 95–110 分鐘｜成果 4 專案重用

再次重用：保留專案規則與流程，換入全新課題

✔ Agent 應該做
沿用 AGENTS.md 與已建立的工作流，只重新確認新任務的具體需求。
✘ Agent 不應該做
不重新生成整個專案環境；不把舊課題的特定題目機械式照搬。
📁 預期檔案產出
output/04-reused/ 目錄下的新課題完整材料。
Prompt 7｜點擊右側按鈕複製 
現在我要測試這個專案是否真的可以重用。

請保留：
- AGENTS.md 的長期規則；
- 已建立的工作方式；
- 檔案管理原則。

這次的新任務是：
請以小學五年級「帶分數加減法」為新課題，設計一份 10 分鐘課堂鞏固練習（共 6 題，含 2 題生活應用題），附教師解答。

請先判斷：
1. 哪些既有規則可以直接重用；
2. 哪些 task-specific requirements 需要重新確認；
3. 哪些舊內容不應直接照搬。

完成必要確認後，將新成果寫入：
output/04-reused/
Prompt 8 第 117–120 分鐘｜培訓離場憑證

記錄真實課堂問題離場（下一場培訓入口）

✔ Agent 應該做
在 notes/ 目錄建立乾淨結構化範本，留給教師親自手動填寫。
✘ Agent 不應該做
絕對不要替老師虛構內容；缺少處必須明確保留空白。
📁 預期檔案產出
notes/next-workshop-problem.md。
Prompt 8｜點擊右側按鈕複製 
請建立 notes/next-workshop-problem.md。

請用簡潔格式記錄：

# 下一場我要解決的真實課堂問題

- 年級：
- 課題：
- 現在最花時間的工作：
- 學生最常出現的問題：
- 我希望 AI Agent 幫我做到甚麼：
- 有甚麼事情我仍然必須由老師親自判斷：

不要替我虛構內容；缺少的地方留給我填寫。

🌟 Starter Pack V2 補充：5 循序 Prompt ＋ 1 完整 Agent 任務

若培訓課堂採用 OpenCode_40人培訓_Starter_Pack_V2 之預載 Skills（textbook-analysis、worksheet-generator、lesson-designer），可直接使用此套精練指令：

V2 旗艦整合任務 多步驟自主執行｜一次產出 4 份教師成品

完整 Agent 任務：讀取 2 份 PDF、調用 3 個 Skills、產出 4 份專業材料

本任務示範如何讓 Agent 在單次授權下，依序調用教材分析、分層生成與 8 分鐘課堂活動，將產出完整落入 02_Output/。

完整 Agent 任務指令｜點擊複製 
請先閱讀 AGENTS.md，並按需要載入 textbook-analysis、worksheet-generator、lesson-designer 三個 skills。

可靠閱讀：
- 01_Input/textbook/P4_分數示範教材_6頁.pdf
- 01_Input/exercises/P4_分數練習_4頁.pdf

如果任何 PDF 無法可靠讀取，立即停止並報告問題，不得臆測。若能可靠讀取，請只在 02_Output/ 建立以下 4 個檔案：

1. 01_教材與知識點分析.md
2. 02_練習題認知層次與錯因.md
3. 03_分層練習_9題.md
4. 04_課前8分鐘TIMSS活動.md

要求：
- 使用繁體中文。
- 每一份都要能直接給小學數學教師使用。
- 不修改 01_Input/。
- 完成後列出你建立的檔名，並用 5 行總結這次 Agent 做了甚麼。
