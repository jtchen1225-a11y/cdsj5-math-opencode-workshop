🧠 核心思維釐清：從 Chatbot 到 AI Agent

打破對生成式 AI 的固有印象，理解為什麼 OpenCode 在資料夾與規則中工作：

維度 傳統 Chatbot（例如網頁對話） OpenCode AI Agent（本培訓模式）
工作場域 孤立的聊天視窗，用完即拋，難以追蹤修改。 在學校專案資料夾內工作，能看見教材與歷程檔。
長期規則 每次對話都要重新貼一段很長的人設與要求。 由 AGENTS.md 統一規定，每次執行自動遵守。
教材讀取 依賴使用者手動複製文字或零散上傳。 直接可靠解析 materials/ 內的 PDF。
需求確認 AI 擅自發揮想像力，產出常脫離年級與進度。 先向老師提出 6 個問題確認規格，寫入 task-spec.md 後才產出。
成果管理 一段文字貼在聊天視窗，需要老師手動整理複製。 直接在 output/ 分階段建立結構化檔案。
專業技能 一般性通用回答，缺乏數學學科工具支持。 載入專業 Skills（教材分析、分層生成、8分鐘活動）。
教師的核心地位（AI 時代守本心）：
AI Agent 負責加速流程與初稿排版；小學數學教師負責教學目標、專業判斷、難度把關與最後驗收。AI 產出絕不等於完成，只有經教師驗收確認才算完成。

每位老師的 Math-Agent-Workshop/ 均採用最嚴謹清晰的權限劃分（點擊卡片可放大翻頁）：

🔍 放大黑板 只讀來源

materials/

存放學校教科書或單元 PDF（如 P5 分數加減法）。Agent 僅能讀取，嚴禁修改或刪除原始檔案。

🔍 放大黑板 需求規格

requirements/

存放 task-spec.md。Agent 在分析後向教師確認教學目標、課時、題數，確認後方可動工。

🔍 放大黑板 成果產出

output/

所有生成檔案的唯一儲存區。依 01-first-version、02-differentiated 等階段分層存放。

🔍 放大黑板 長期憲法

AGENTS.md

定義學校教學常態規則（澳門常用繁體中文、中英文術語一致、嚴禁處理學生個資等）。

🔒
學生隱私紅線：嚴禁將真實學生姓名、學號、成績、家長聯絡方式上傳至 OpenCode。練習紙一律保留空白填寫欄。
🔒
金鑰安全保護：40 位教師使用獨立個人 API Key，嚴禁在專案程式碼中記錄金鑰或密碼。
🔒
原始教材保護：materials/ 檔案如無法可靠解析，Agent 必須停止並回報，絕不可自行猜測內容。

⚡ 40 人現場錯峰與課前 4 件事

確保 40 位教師同時在校園 Wi-Fi 環境下流暢實操的關鍵技術規範：

課前第 1 步

安裝 Node.js LTS

由官網下載 LTS 版本（如 v24.x），使用預設選項一路 Next，勾選 Add to PATH。

課前第 2 步

安裝 OpenCode

開啟「命令提示字元 cmd」，輸入指令：
npm install -g opencode-ai

課前第 3 步

加入 Workspace & Key

接受邀請加入學校 Workspace，獲取專屬 API Key，在 OpenCode 中輸入 /connect。

課前第 4 步

一鍵環境檢查

在 Starter Pack 中雙擊 00_一鍵檢查環境.bat，確認三項均顯示版本號即 PASS。

🚦 課堂 A/B/C/D 錯峰送出節奏（防範 429 限流）

為避免 40 台電腦在同一秒向 API 伺服器送出密集請求引發限流，現場分為 4 組錯峰敲擊 Enter：

組別 座位範圍 送出時間差 現場指令口訣
A 組 座位 01–10 號 講師宣布後 立即送出（0 秒） 「A 組按 Enter，其他組先看畫面」
B 組 座位 11–20 號 間隔 +15 秒 後送出 「B 組請送出」
C 組 座位 21–30 號 間隔 +30 秒 後送出 「C 組請送出」
D 組 座位 31–40 號 間隔 +45 秒 後送出 「D 組請送出」
